### 4. Исследование альтернатив

## Jira

Источник:  
https://www.atlassian.com/software/jira

Jira — система управления проектами и задачами, широко используемая в разработке программного обеспечения.

### Возможности

- управление задачами
- доски Scrum и Kanban
- отслеживание прогресса
- интеграция с системами контроля версий
- гибкая настройка workflow

### Ограничения

- бесплатный тариф ограничен количеством пользователей
- некоторые функции доступны только в платных тарифах
#### Реализация лабораторной работы в Jira

Аналогичный процесс можно было бы реализовать в Jira следующим образом:

1. Создать проект.
2. Настроить Kanban-доску.
3. Добавить стадии workflow:
   - Backlog
   - In Progress
   - Review
   - Done
4. Создать задачи (Issues) для каждого этапа курсовой работы.
5. Установить связи между задачами.
6. Назначить исполнителей.
7. Использовать систему Pull Requests в интегрированном репозитории.
